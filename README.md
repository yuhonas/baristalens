# BaristaLens

Latte art photo comparator with pixel-accurate alignment, symmetry guides, and a competition scoring rubric.

Built with Alpine.js, Tailwind CSS v4 and Vite.

## Run locally

**Prerequisites:** [Bun](https://bun.sh)

1. Install dependencies: `bun install`
2. Start the dev server: `bun run dev` (http://localhost:3000)

## Scripts

| Script | What it does |
|---|---|
| `bun run dev` | Vite dev server on port 3000 |
| `bun run build` | Production build to `dist/` |
| `bun run preview` | Serve the production build |
| `bun run typecheck` | Type-check with `tsc` |
| `bun run lint` | ESLint (TypeScript, HTML, Tailwind) |
| `bun run lint:fix` | ESLint with auto-fix |
